# Database

This folder mirrors the Supabase database layer for the v2 project structure.

- `migrations/` contains SQL migrations copied from `supabase/migrations`.
- `functions/` contains Supabase Edge Functions copied from `supabase/functions`.
- `seeders/`, `schemas/`, `triggers/`, `policies/`, and `backups/` are reserved for database organization as the project grows.

The original `supabase/` folder is intentionally kept at the project root for Supabase CLI compatibility.
